# Google Apps Script 버전 — 본인 전용 시험판

기존 GitHub Pages 사이트와 별개입니다. 이 폴더의 파일은 GitHub Pages로 배포하지 않습니다. 기존 브라우저 데이터는 자동으로 가져오지 않으며 새 스프레드시트에서 빈 학생 명부로 시작합니다.

## 처음 설정

1. Google 스프레드시트를 새로 만들고 `교무수첩 데이터`라고 이름을 정합니다.
2. 확장 프로그램 → Apps Script를 엽니다.
3. `Code.gs`의 기본 코드를 지우고 이 폴더의 `Code.gs` 전체를 붙여넣습니다.
4. 파일 옆 + → HTML을 선택하고 이름을 `Index`로 입력합니다. 이 폴더의 `Index.html` 전체를 붙여넣습니다. 두 파일은 각각 저장합니다. `build.mjs`와 README는 Apps Script에 복사하지 않습니다.
5. 상단 함수 선택에서 `setupNotebook`을 선택하고 실행합니다. 최초에는 Google 계정 권한 승인이 필요합니다. 본인이 작성한 프로젝트인지 확인한 후 스프레드시트 접근 권한을 승인합니다. 학교 정책으로 차단되면 관리자에게 허용 여부를 확인하세요.
6. 실행 완료 후 배포 → 새 배포 → 유형 선택(톱니) → 웹 앱을 선택합니다.
7. 실행 사용자: **나**, 액세스 권한: **나만**으로 설정합니다. 계정에 따라 표현이 다를 수 있습니다. 나만이 없다면 전체 공개로 대신 배포하지 말고 사용 가능한 옵션을 확인하세요.
8. 배포 후 제공된 웹 앱 URL(`/exec`로 끝남)을 엽니다. 다른 컴퓨터에서도 같은 Google 계정으로 로그인하여 이 주소를 엽니다.

`doGet`은 실행 버튼으로 실행하지 않습니다. 웹 앱 주소로 접속할 때 자동 호출됩니다. 프로젝트 편집기 주소와 웹 앱 주소는 다릅니다.

## 사용하는 방법

학생 추가, 보호자 최대 2명, 진로 추가 정보, 엑셀 양식 다운로드와 표 붙여넣기, 기록 작성과 @학생 연결, 검색과 중요 표시가 포함되어 있습니다. 데이터는 `교무수첩_저장소` 시트에 프로그램 전용 형식으로 저장됩니다. 이 시트를 직접 수정하거나 삭제하지 마세요. 기존 다른 시트의 데이터는 변경하지 않습니다.

첫 등록은 가상 학생으로 시험하세요. 저장 뒤 화면 아래 `클라우드 저장 완료`를 확인하고 창을 닫으세요. 작성 중인 폼은 저장 버튼을 눌러야 저장됩니다. 여러 컴퓨터에서 같은 계정으로 접근할 수 있으나 변경 내용은 다른 창에 실시간으로 전송되지 않으므로 새로고침으로 불러옵니다. 다른 창에서 먼저 저장했다면 덮어쓰기를 거부하고 편집을 중지합니다. 안내에 따라 현재 내용을 JSON으로 백업하고 새로고침하세요. JSON 자동 복원 기능은 아직 없으므로 필요한 내용을 보고 다시 입력해야 합니다.

저장 용량은 초기 시험용으로 JSON 기준 200만 문자까지로 제한했습니다. 스프레드시트의 버전 기록은 별도 백업 정책을 대신하지 않습니다.

## 계정과 공개 범위

본인 계정만 허용하는 서버 검사를 포함합니다. 다른 교사와 함께 쓰는 버전은 별도 권한 설계가 필요합니다. Google 계정 이메일을 확인할 수 없는 실행 환경은 접근을 거부합니다. 이때 공개 범위를 넓히거나 서버의 소유자 검사를 지우지 말고 계정·배포 설정을 확인하세요.

Google Apps Script의 온라인 실행과 배포는 사용자의 Google 계정에서 진행해야 합니다. 로컬에서는 서버 API 모의 환경과 화면 연동을 검증했으며 Google 서버의 권한 승인·실제 시트 저장·배포는 아직 확인하지 않았습니다. 실제 학생 정보 사용 전 학교 정책, 저장·백업·삭제 기준과 접근 권한을 확인해야 합니다.

## 화면 코드를 다시 생성할 때

기존 웹앱 원본에서 `Index.html`을 생성했습니다. 이 개발 환경에서는 `node teacher-notebook-apps-script/build.mjs`로 다시 생성할 수 있습니다. 생성된 HTML에는 CSS, 자바스크립트와 엑셀 양식이 들어 있어 별도 호스팅이 필요 없습니다.
