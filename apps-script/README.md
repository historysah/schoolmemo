# 해밀고-하나조노고 3차 온라인 교류

사진 없는 5팀 문자 교류 앱입니다. 한 개의 웹앱 주소에서 1~5팀을 선택합니다. 글을 보내면 한국어 ↔ 일본어로 번역하고, 원문과 번역을 함께 표시합니다. 약 5초 간격으로 대화를 갱신하며 비활성 탭에서는 갱신을 멈춥니다. 최근 200개 메시지만 화면에 표시하고 시트에는 최대 5,000개를 보관합니다.

이 폴더의 `Code.gs`, `Index.html` 두 파일만 Google에 복사하면 됩니다. 기존 `exchange/`는 Node 서버판으로, Apps Script 설정에는 사용하지 않습니다. Render 가입과 별도 서버 설치는 필요 없습니다. OpenAI API 사용료와 Google 서비스 사용 한도는 적용됩니다.

## 기존 배포에 이번 수정 적용하기

1. GitHub의 최신 `Code.gs`와 `Index.html` 전체 내용을 기존 Apps Script의 같은 파일에 각각 덮어쓰고 저장합니다. API 키 등 스크립트 속성은 바꾸지 않습니다.
2. **배포 → 배포 관리 → 현재 배포의 수정(연필) → 버전: 새 버전 → 배포**를 선택합니다. 새 배포를 따로 만드는 대신 기존 배포를 갱신하면 기존 학생용 주소를 유지할 수 있습니다.
3. 웹앱을 새로고침하고 다시 입장해 확인합니다. GitHub 파일 변경만으로 Google의 현재 배포가 자동 갱신되지는 않습니다.

### 이번 버전의 기능

- 사이트 제목을 **해밀고-하나조노고 3차 온라인 교류**로 표시합니다.
- 첫 입장 화면에 학생 접속용 QR코드와 주소 복사 버튼을 제공합니다. QR은 Google의 정식 `/exec` 배포 주소를 브라우저 안에서 생성하며, 입장 코드·API 키·비밀번호는 포함하지 않습니다. 외부 QR 이미지 서비스나 CDN은 사용하지 않습니다.
- 폼·버튼·대화 글자의 크기와 대비를 높이고 불필요한 장식 문구를 줄였습니다. 한국어·일본어의 필수 사용 안내는 유지합니다.
- **오른쪽 위 ‘교사용 로그인’**을 누르면 별도의 큰 입력창이 열립니다. 이름·행사 입장 코드·교사 비밀번호·팀·언어를 입력하고 ‘교사로 입장’을 누릅니다. 학생 입장 폼에는 교사 비밀번호가 없습니다.
- 입장 화면은 ‘이름 · お名前’를 입력하도록 안내합니다.
- 대화와 별개인 **우리 팀 의견 정리** 창을 제공합니다. 팀원 누구나 수정하고 ‘팀 의견 저장’을 눌러 공유할 수 있습니다. 미저장 초안은 다른 팀원에게 보이지 않습니다.
- 의견은 작성 언어를 선택할 수 있고 저장 후 자동 번역됩니다. 다른 팀원이 먼저 저장하면 기존 초안은 유지되고, ‘최신 의견 불러오기’ 후 다시 정리하도록 안내합니다. 여러 사람이 타이핑하는 내용을 글자마다 동기화하는 편집기는 아닙니다.
- **모든 팀 의견 확인하기**에서 1~5팀의 저장된 의견과 번역을 함께 봅니다. 다른 팀 대화는 공유하지 않으며, 다른 팀 의견은 읽기만 가능합니다. 열린 의견 창도 대화와 같은 약 5초 간격으로 갱신합니다.
- 교사에게 **현재 팀 대화 삭제**와 **모든 팀 전체 초기화**를 제공합니다. 후자는 확인 후 5팀 전체 대화와 의견을 초기화하고 모든 참여자의 기존 세션을 종료합니다. 교사도 다시 입장해야 합니다. 행사 코드·교사 비밀번호·API 키 설정은 유지합니다.
- `SAI_MESSAGES`는 기존 채팅 저장 형식을 유지하고, 팀 의견은 새 `SAI_OPINIONS` 탭에 자동 생성합니다. 기존 자료를 코드를 업데이트하는 것만으로 지우지 않습니다. 행사 중 두 탭의 구조를 직접 수정하지 마세요.

## 1. 교사용 Google 스프레드시트 만들기

1. https://sheets.google.com 에 교사 Google 계정으로 로그인합니다.
2. 빈 스프레드시트를 만들고 제목을 `한일 역사 교류 대화 기록`으로 정합니다.
3. 시트는 교사 본인만 접근하도록 유지합니다. 학생이나 일본 학교에 시트 편집 권한을 줄 필요가 없습니다.
4. 주소에서 `/d/`와 `/edit` 사이를 복사해 둡니다. 이것이 `SPREADSHEET_ID`입니다.

예: `https://docs.google.com/spreadsheets/d/여기가_ID/edit`라면 `여기가_ID` 부분만 복사합니다. 전체 주소가 아닙니다.

## 2. Apps Script 열기

스프레드시트 위쪽 메뉴에서 **확장 프로그램 → Apps Script**를 선택합니다. 새 탭에서 프로젝트 이름을 `해밀고-하나조노고 3차 온라인 교류`로 바꿉니다.

## 3. 파일 두 개 복사

1. 이 저장소의 [Code.gs](https://github.com/historysah/schoolmemo/blob/main/apps-script/Code.gs)를 엽니다. 코드 복사 버튼 또는 Raw 화면에서 전체 내용을 복사합니다.
2. Apps Script 왼쪽의 기본 `Code.gs` 파일을 선택합니다. 기존 `myFunction` 코드를 전부 지우고 복사한 내용을 붙여넣습니다.
3. Apps Script의 **파일 옆 + → HTML**을 선택합니다. 이름은 정확히 `Index`로 입력합니다. `.html`은 자동으로 붙습니다.
4. 저장소의 [Index.html](https://github.com/historysah/schoolmemo/blob/main/apps-script/Index.html) 전체 내용을 복사합니다. 방금 만든 HTML 파일의 기본 내용을 전부 지우고 붙여넣습니다.
5. 저장 버튼 또는 `Ctrl+S`(Mac: `Cmd+S`)로 저장합니다.

이 파일들은 샘플 조각이 아니라 각각 전체 파일입니다. 테스트 폴더의 파일은 복사하지 않습니다. API 키를 코드에 붙여넣지 않습니다.

## 4. 비공개 스크립트 속성 설정

왼쪽 **프로젝트 설정(톱니바퀴) → 스크립트 속성 → 스크립트 속성 추가**에서 다음 네 개를 등록하고 저장합니다.

| 속성 | 값 |
| --- | --- |
| `SPREADSHEET_ID` | 1단계에서 복사한 스프레드시트 ID |
| `EVENT_CODE` | 학생들에게 알려줄 추측하기 어려운 행사 입장 코드 |
| `TEACHER_PASSWORD` | 교사만 아는 12자 이상의 비밀번호 |
| `OPENAI_API_KEY` | OpenAI에서 발급받은 API 키 |

선택 사항: `OPENAI_MODEL`을 추가하면 모델을 바꿀 수 있습니다. 기본값은 `gpt-4.1-mini`이며 Chat Completions API, temperature, max_completion_tokens를 지원해야 합니다.

API 키 없이 먼저 시험하려면 `OPENAI_API_KEY`는 나중에 추가해도 됩니다. 번역이 설정되지 않았다는 안내와 함께 원문 대화가 작동합니다. API 키는 이 프로젝트의 편집자는 볼 수 있으므로 학생에게 Apps Script 편집 권한을 주지 마세요. 속성 화면이나 키가 보이는 화면을 공유하지 마세요.

## 5. 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택의 톱니바퀴에서 **웹 앱**을 선택합니다.
3. 설명은 `역사 교류 1차`처럼 작성합니다.
4. **다음 사용자 인증 정보로 실행 / 실행 사용자**는 **나(교사 계정)**를 선택합니다. 학생 계정으로 실행하도록 설정하지 않습니다.
5. **액세스 권한이 있는 사용자**는 양국 학생이 접근할 수 있는 **모든 사용자(Anyone)**를 선택합니다. Google 로그인 없는 접근이 가능한 항목인지 확인합니다.
6. **배포**를 누르고, 본인이 만든 이 프로젝트가 해당 스프레드시트와 외부 번역 API에 접근하도록 권한을 승인합니다. 본인의 프로젝트인지와 요청 권한을 확인하세요.
7. 계정 정책에 따라 ‘Google에서 확인하지 않은 앱’ 안내가 나올 수 있습니다. 본인이 만든 이 프로젝트임을 확인한 경우에만 고급 메뉴의 프로젝트 이동으로 진행합니다. 조직 관리자가 차단했다면 우회하지 말고 관리자에게 사용 가능 여부를 확인합니다.
8. 결과의 **웹 앱 URL**을 복사합니다. 학생용 주소는 보통 `/exec`로 끝납니다. 편집기 주소나 테스트용 `/dev` 주소를 보내지 않습니다.

학교 계정에서 ‘모든 사용자’가 없거나 외부 접속이 차단될 수 있습니다. 일본 학생 계정이나 로그아웃 상태에서 반드시 시험하세요. 제한이 있으면 학교 관리자에게 문의하고, 학교가 허용하는 계정·서비스로 운영합니다.

## QR코드 주소 확인

일반적으로 별도 설정 없이 정식 배포 주소를 자동으로 가져옵니다. 화면에 보이는 `googleusercontent.com/userCodeAppPanel` 등의 임시 iframe 주소는 사용하지 않습니다.

- 기존 배포를 ‘새 버전’으로 갱신하고 학생용 `/exec` 주소로 열어 QR을 확인하세요. 휴대전화로 스캔해 동일한 입장 화면이 열리는지 시험하세요.
- 개발용 `/dev` 주소나 아직 배포되지 않은 프로젝트에서는 잘못된 QR을 만들지 않고 주소 확인 안내를 표시합니다.
- QR이 표시되지 않거나 특정 배포 주소를 고정하려면 스크립트 속성에 선택 사항인 **`WEB_APP_URL`**을 추가하고 값에 **배포 관리에서 복사한 전체 `/exec` 주소**를 넣으세요. 주소에는 입장 코드나 비밀번호, 쿼리 문자열을 붙이지 않습니다. 속성 저장 후 웹앱을 새로고침합니다.
- QR로 입장 화면에 접속해도 행사 입장 코드는 별도로 입력해야 합니다. 학교 계정의 외부 접속 정책은 그대로 적용됩니다.

## 6. 실제 시험

1. 웹앱 주소를 열고 행사 코드, 이름, 사용 언어, 팀을 선택합니다.
2. 교사는 오른쪽 위 ‘교사용 로그인’을 눌러 별도 창에서 입장 코드와 교사 비밀번호를 입력합니다.
3. 다른 브라우저/기기에서 같은 팀으로 입장합니다.
4. 한국어 글을 보내 일본어 번역이 나오는지, 반대로도 번역되는지 확인합니다. 번역에는 수 초 이상 걸릴 수 있습니다.
5. 2팀으로 입장하면 1팀 글이 안 보이는지 확인합니다. 모든 팀은 같은 행사 코드를 사용하므로 학생이 다른 팀을 선택하는 것은 가능합니다.
6. API 키 없이 쓴 예전 글은 작성자나 교사가 ‘번역 재시도’를 누릅니다.
7. 스프레드시트의 `SAI_MESSAGES` 탭이 자동으로 생성되고 원문·번역이 저장되는지 확인합니다. 이 탭의 제목·열 순서·셀은 행사 중에 수동 변경하지 마세요.
8. 일본 측 담당 교사와 학생 접속 환경에서도 시험한 후 실제 인원에 가까운 규모로 짧은 예행연습을 합니다.

실제 Google 서비스에서 실행하는 권한 승인과 OpenAI 결제·모델 접근 여부는 로컬 테스트로 대신 검증할 수 없습니다. 번역 실패 시 API 키·결제 잔액·모델 접근과 Google Apps Script 실행 내역을 확인하세요. 키를 채팅이나 오류 캡처에 포함하지 마세요.

## 7. 학생에게 안내

‘웹앱 주소, 행사 입장 코드, 본인 팀 번호’를 전달합니다. 학생은 Google 시트나 코드가 아니라 웹앱 주소만 엽니다. 입력한 이름은 참여자에게 표시됩니다. 개인 연락처·불필요한 민감 정보는 입력하지 않도록 안내하세요. 글은 외부 AI 서비스로 전송되며 AI 번역은 틀릴 수 있습니다.

## 활동 후 / 나중에 수정

- 교사의 ‘현재 팀 대화 삭제’는 현재 팀 채팅만 삭제하며 의견은 유지합니다. ‘모든 팀 전체 초기화’는 5팀 전체 대화와 의견을 지우고 재입장을 요구합니다. 이는 현재 시트 자료의 초기화이며 Google 버전 기록·백업까지 영구 삭제한다고 보장하지 않습니다. 학교 보관·삭제 정책에 맞게 원본 시트와 프로젝트, Google 보관 기록을 관리하세요.
- 교류가 끝나면 **배포 → 배포 관리**에서 배포를 보관처리해 접속을 닫을 수 있습니다. 같은 프로젝트의 다른 활성 배포도 확인하세요.
- 코드를 바꾼 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**로 갱신합니다. 파일 저장만으로 기존 `/exec` 배포 코드가 바뀌지는 않습니다. 스크립트 속성은 실행 때 읽으므로 키만 바꾸는 경우 코드 버전 갱신은 필요하지 않습니다. 브라우저는 새로고침하세요.
- 세션은 최대 6시간이며 Google 캐시가 먼저 제거되면 다시 입장해야 합니다. 같은 브라우저 탭에서는 새로고침 후 세션 복원을 시도합니다. 재입장한 학생의 옛 글은 교사가 관리할 수 있습니다.
- 1,000자 제한, 세션별 분당 8회 전송·재번역 제한이 있습니다. 이는 엄격한 금액 상한이 아니며 Google 캐시·실행 한도와 OpenAI 사용 요금은 별도입니다. 행사 코드는 강한 학생 신원 인증이 아닙니다.

## 검증 범위

저장소 루트에서:

```sh
node --test apps-script/tests/server.test.mjs
node apps-script/tests/browser.mjs
```

두 번째 명령은 루트 `npm ci`와 `/usr/bin/chromium`이 필요합니다. Apps Script 저장소·잠금·캐시·번역 제공자·google.script.run을 모의 구현해 인증, 팀 분리, 양방향 번역, 실패·재시도, 중복 방지, 의견 동시 수정 충돌, 전체 의견 열람, 교사 전체 초기화와 세션 종료, 늦은 번역에 의한 복구 방지, 데스크톱·모바일 UI, 큰 교사 로그인 창, QR 이미지 표시와 배포 URL 검증을 수행합니다. 실제 Google 계정 배포나 실제 OpenAI 호출의 통과를 의미하지 않습니다.

공식 참고: [웹앱 배포](https://developers.google.com/apps-script/guides/web), [Google 사용 한도](https://developers.google.com/apps-script/guides/services/quotas).

## QR 코드 라이선스

`Index.html`에 qrcode-generator 1.4.4(MIT, Copyright 2009 Kazuhiko Arase)를 포함했습니다. 별도 설치나 추가 Apps Script 파일은 필요 없습니다. 원 저작권·허가 문구도 HTML에 포함되어 있습니다. 배포 주소를 QR로 변환할 때 네트워크 요청을 보내지 않습니다.
