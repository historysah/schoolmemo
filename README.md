# 교무수첩

가상 데이터로 시작하는 한국어 교무수첩 웹앱입니다. 학생 관리, 상담·회의 기록, 여러 학생 연결, 검색, 중요 기록 표시를 제공합니다.

## 한일 역사 교류 앱

사진 없이 5팀 문자 대화와 한일 AI 번역을 사용하는 Google Apps Script 버전은 [apps-script 안내서](apps-script/README.md)를 따르세요. `Code.gs`, `Index.html` 두 파일을 사용하며 별도 Node 서버나 Render 가입은 필요하지 않습니다. OpenAI API 키는 Google 프로젝트의 비공개 스크립트 속성에 설정합니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다. 현재 환경은 Node.js 24입니다.

```sh
cd /workspace/schoolmemo
npm ci
npm run dev -- --port 5173
```

배포 파일 생성: `npm run build` (결과: `dist/`). 브라우저 기능 검사: `npm test`. 현재 클라우드 환경의 `/usr/bin/chromium`을 사용합니다. 다른 환경에서는 `playwright.config.js`의 실행 경로를 설치된 Chromium 경로로 변경하세요.

## 사용 방법

- 학생 명부 및 인적사항에서 학생을 추가하고, 학생 카드를 선택해 정보를 수정합니다.
- 기록 추가하기에서 날짜, 제목, 내용을 입력합니다.
- 내용 입력 중 `@`와 학생 이름 일부를 입력하면 선택 목록이 나타납니다. 학생을 선택하면 해당 학생과 기록이 연결됩니다. 학생 상세 화면에서 추가하는 기록에는 그 학생이 먼저 연결됩니다.
- 관련 학생의 `×`를 누르면 연결이 해제됩니다. 글 속 이름은 그대로 남으며, 학생별 기록 목록은 관련 학생 연결을 기준으로 표시됩니다.
- 기록 제목이나 수정 버튼으로 수정하고, 삭제 버튼으로 삭제할 수 있습니다. 삭제 전 확인을 받습니다.
- 별표로 중요 표시를 전환하고 중요 기록만 보기로 필터링합니다. 학생 상세 화면에서도 사용할 수 있습니다.

## 학생 정보와 일괄 입력

- 학생 명부와 상세 화면에는 성을 표시하는 원형 아이콘이 없습니다.
- 기본 정보 수정에서 보호자를 최대 2명 입력합니다. 각 보호자는 관계(부/모/기타), 성함, 연락처로 구성됩니다. 보호자 입력은 선택 사항이며, 성함이나 연락처를 입력하면 관계를 선택해야 합니다.
- 기존 학부모 정보는 보호자 1로 보존하고 관계는 `기타`로 옮깁니다. 실제 관계는 기본 정보 수정에서 확인해 변경하세요.
- 추가 정보 입력 / 수정은 기본 정보와 별도 화면에서 장래희망, 희망 대학, 희망 학과, 기타를 저장합니다. 기타는 여러 줄의 서술형 입력란입니다.
- 학생 명부의 일괄 정보 입력에서 일반 엑셀 `.xlsx` 양식을 내려받아 가상 학생 데이터를 작성하고 표를 복사하여 붙여넣습니다. 입력 내용 확인 후 미리보기에서 확인하고 일괄 등록하기를 누릅니다.
- 엑셀 파일의 학생 입력 시트에서 두 번째 줄부터 입력합니다. 300행의 서식, 보호자 관계 드롭다운, 연락처 텍스트 서식을 제공합니다. 사용 안내 시트에서 입력·등록 순서를 확인할 수 있습니다.
- 이름·학년·반·번호 네 열만 붙여넣어도 됩니다. 선택 정보를 포함하면 양식 열 순서를 사용하거나 제목 행을 함께 복사하세요. 빈 칸도 그대로 복사해야 합니다. 엑셀에서 복사한 여러 줄 셀도 지원합니다.
- 필수값, 보호자 관계, 학년·반·번호 중복을 검증합니다. 오류가 있으면 전체 등록을 막으며 기존 학생은 덮어쓰지 않습니다. 같은 학년·반·번호가 있으면 기본 정보 수정으로 변경하세요.

## 스티치 디자인 적용

상단 검색, 왼쪽 내비게이션, 기록 카드와 작성 패널을 갖춘 화면으로 구성했습니다. 넓은 화면에서는 기록과 작성 패널을 나란히 표시하고, 작은 화면에서는 세로로 표시합니다. 오른쪽 작성 패널은 저장 버튼으로 기록을 저장합니다. 검색이나 별표 변경 중에는 입력 초안이 유지되지만 저장 전 새로고침하면 초안은 사라집니다. 인쇄 및 PDF 내보내기는 브라우저 인쇄 창을 엽니다.

스티치 예시의 NEIS 연동, 보안 모드, 자동 저장, 기록 분류는 현재 구현하지 않았으며 활성 상태로 표시하지 않습니다. 상담과 회의는 기존 요구사항대로 하나의 통합 기록입니다. 기존 브라우저 저장 키를 유지하므로 저장한 학생과 기록을 계속 사용할 수 있습니다.

## 저장 위치와 범위

데이터는 현재 기기, 현재 브라우저, 현재 사이트 주소의 `localStorage`에 `schoolmemo.demo.v1` 키로 저장합니다. 새로고침 뒤에도 유지되지만 다른 기기나 브라우저와 동기화되지 않습니다. 사이트 주소나 포트가 바뀌면 별도 저장 공간을 사용합니다. 브라우저 사이트 데이터를 삭제하면 기록도 사라집니다. 서버 데이터베이스와 백업은 없습니다.

학생 이름, 연락처, 주소 등 기본 제공 데이터는 모두 가상입니다. 실제 학생 정보를 사용하기 전에는 로그인, 접근 권한, 서버 저장 및 백업, 보관·삭제 정책을 구현해야 합니다.
