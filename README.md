# 교무수첩

가상 데이터로 시작하는 한국어 교무수첩 웹앱입니다. 학생 관리, 상담·회의 기록, 여러 학생 연결, 검색, 중요 기록 표시를 제공합니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다. 현재 환경은 Node.js 24입니다.

```sh
cd /workspace/schoolmemo
npm ci
npm run dev -- --port 5173
```

배포 파일 생성: `npm run build` (결과: `dist/`). 브라우저 기능 검사: `npm test`. 현재 클라우드 환경의 `/usr/bin/chromium`을 사용합니다. 다른 환경에서는 `playwright.config.js`의 실행 경로를 설치된 Chromium 경로로 변경하세요.

## 사용 방법

- 학생 관리에서 학생을 추가하고, 학생 카드를 선택해 정보를 수정합니다.
- 기록 추가하기에서 날짜, 제목, 내용을 입력합니다.
- 내용 입력 중 `@`와 학생 이름 일부를 입력하면 선택 목록이 나타납니다. 학생을 선택하면 해당 학생과 기록이 연결됩니다. 학생 상세 화면에서 추가하는 기록에는 그 학생이 먼저 연결됩니다.
- 관련 학생의 `×`를 누르면 연결이 해제됩니다. 글 속 이름은 그대로 남으며, 학생별 기록 목록은 관련 학생 연결을 기준으로 표시됩니다.
- 기록 제목이나 열기 / 수정 버튼으로 수정 및 삭제할 수 있습니다. 삭제 전 확인을 받습니다.
- 별표로 중요 표시를 전환하고 중요 기록만 보기로 필터링합니다. 학생 상세 화면에서도 사용할 수 있습니다.

## 저장 위치와 범위

데이터는 현재 기기, 현재 브라우저, 현재 사이트 주소의 `localStorage`에 `schoolmemo.demo.v1` 키로 저장합니다. 새로고침 뒤에도 유지되지만 다른 기기나 브라우저와 동기화되지 않습니다. 사이트 주소나 포트가 바뀌면 별도 저장 공간을 사용합니다. 브라우저 사이트 데이터를 삭제하면 기록도 사라집니다. 서버 데이터베이스와 백업은 없습니다.

학생 이름, 연락처, 주소 등 기본 제공 데이터는 모두 가상입니다. 실제 학생 정보를 사용하기 전에는 로그인, 접근 권한, 서버 저장 및 백업, 보관·삭제 정책을 구현해야 합니다.
