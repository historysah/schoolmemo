# 사이 · 한일 역사 교류

기존 교무수첩과 별개로 실행하는 한국어·일본어 소그룹 대화 앱입니다. 팀별 주소 `/team/1`부터 `/team/5`, 행사 코드 입장, 닉네임·언어 선택, 서버 공유 대화, 사진 압축·공유, 원문·AI 번역 병기, 본인 글 삭제와 교사 삭제 기능을 제공합니다. 사진 속 글자 인식과 음성 통역은 포함하지 않습니다.

## 1. API 키 없이 먼저 실행

Node.js 22.12 이상을 사용합니다. 외부 npm 의존성 설치가 필요 없습니다.

```sh
cd /workspace/schoolmemo/exchange
cp .env.example .env
```

`.env`를 편집해 `EVENT_CODE`를 학생에게 공유할 행사 코드로 바꾸세요. `TEACHER_PASSWORD`는 교사만 아는 12자 이상의 비밀번호로 지정하세요. `OPENAI_API_KEY`는 비워두어도 됩니다. 예제 파일을 다시 복사해 기존 설정을 덮어쓰지 마세요.

```sh
npm start
```

기본 포트는 3000입니다. API 키가 없으면 실제 번역 대신 ‘API 설정 후 번역할 수 있어요’가 표시됩니다. 글과 사진 공유는 작동합니다. 교사는 같은 입장 화면에서 ‘교사로 입장’을 펼쳐 비밀번호를 추가로 입력합니다. 다른 팀을 선택하면 입장 코드를 다시 입력해야 합니다. 언어를 바꾸려면 나간 후 다시 입장하세요.

## 2. 나중에 AI 번역 켜기

1. OpenAI API 플랫폼 https://platform.openai.com/ 에 로그인합니다. ChatGPT 구독과 API 사용 요금은 별개입니다.
2. 프로젝트의 Billing에서 결제 수단·크레딧 상태를 확인하고, 사용 알림과 예산을 설정하세요. 예산 알림만으로 초과 사용이 반드시 차단되지는 않습니다.
3. 프로젝트의 API keys에서 새 비밀 키를 만듭니다. **키를 채팅, 학생 화면, GitHub, 공유 문서에 붙이지 마세요.**
4. 이 서버의 비공개 `.env` 파일에서 `OPENAI_API_KEY=` 오른쪽에 키를 입력하고 저장합니다. 호스팅 서비스에서는 해당 서비스의 비밀 환경 변수 설정에 같은 이름으로 등록하세요.
5. 서버를 종료한 뒤 `npm start`로 다시 시작합니다. 브라우저도 새로고침하세요.
6. 학생 계정 두 개로 한국어와 일본어 문장을 각각 보내 실제 번역을 확인하세요. 기존 미번역 글은 작성자나 교사가 ‘번역 재시도’를 누릅니다.

기본 모델은 `gpt-4.1-mini`입니다. 프로젝트에서 사용 가능한 다른 Chat Completions 지원 모델은 `OPENAI_MODEL`로 설정할 수 있습니다. 번역 실패 시 API 결제·모델 접근·서버에서 `api.openai.com` HTTPS 접속 가능 여부를 확인하세요. 키는 브라우저로 전송하지 않습니다. 사진은 OpenAI에 보내지 않고 글과 사진 설명만 번역합니다. 역사 용어 공통 용어집 UI는 아직 포함하지 않았습니다.

## 3. 실제 교류에 배포

학생들이 같은 서버 주소에 접속해야 공유됩니다. 각자의 컴퓨터에서 따로 실행하면 서로 연결되지 않습니다. 이 앱은 Node 프로세스를 실행할 수 있고 **영구 저장 디스크**가 있는 호스팅이 필요합니다. 정적 웹 호스팅만으로는 동작하지 않습니다.

- HTTPS를 제공하는 호스팅에 배포하고 `COOKIE_SECURE=true`로 설정합니다.
- 호스팅의 환경 변수에 행사 코드, 교사 비밀번호, API 키를 등록합니다. `.env` 파일을 공개 업로드하지 마세요.
- `DATA_DIR`를 영구 볼륨 경로로 지정합니다. 기본 저장 경로는 앱의 `data/`입니다. 자동 동기화되지 않는 여러 서버 인스턴스 대신 **단일 서버 프로세스**로 운영하세요.
- 사진·메시지는 서버 디스크의 JSON 파일에 저장합니다. 소규모 행사 시제품용이며 대규모·상시 운영에는 데이터베이스와 오브젝트 저장소 전환이 필요합니다. 전체 3,000개 메시지 제한, 사용자별 분당 12회 전송 제한이 있습니다. 사진이 많으면 JSON 저장 비용이 커지므로 행사 전 실제 인원으로 점검하세요.
- 행사 코드는 팀별 접근을 엄격하게 분리하는 권한 체계가 아닙니다. 코드를 아는 학생은 다른 팀에도 입장할 수 있습니다. 학생 실명 인증, 교사 계정 관리, 감사 기록은 포함하지 않습니다.
- 세션은 12시간이며 서버 재시작 시 다시 입장해야 합니다. 같은 세션에서는 본인 글을 삭제할 수 있고, 재입장 후 예전 글은 교사가 삭제할 수 있습니다.
- 얼굴 사진 공유 동의와 외부 AI 서비스로 전송되는 글의 학교 정책을 확인하세요. 사진을 브라우저에서 다시 인코딩해 메타데이터를 제거하지만, 사진 내용의 개인정보까지 제거하지는 않습니다.
- 자동 보관 기한은 없습니다. 활동 종료 후 교사로 각 팀에 입장하여 ‘현재 팀 기록 전체 삭제’를 사용하세요. 서버 백업이 있다면 별도 보관 정책에 따라 삭제해야 합니다.

행사 전 서로 다른 기기 두 대로 입장, 양방향 번역, 사진 공유, 교사 삭제, 연결 복구를 확인하세요. AI 번역은 사실 검증이 아니며 역사적 해석과 고유명사는 교사가 확인해야 합니다.

## 검증

```sh
npm test
```

서버 통합 테스트는 별도 임시 데이터 경로와 포트를 사용합니다. 실제 API 키 없이 접근 제어·팀 분리·글/사진 공유·삭제·영구 저장을 검증합니다. 번역 제공자의 모의 응답으로 양방향 번역 성공과 실패 상태도 검사합니다. 실제 OpenAI 번역은 키 설정 후 별도로 확인해야 합니다.

브라우저 검사도 실행하려면 저장소 루트에서 `npm ci` 후, 별도의 터미널에서 다음 테스트 서버를 시작하세요(실제 행사 서버와 함께 사용하지 마세요).

```sh
EVENT_CODE=BRIDGE-TEST TEACHER_PASSWORD=teacher-test-password DATA_DIR=/tmp/history-bridge-browser PORT=3000 node exchange/server.js
```

다른 터미널에서 `node exchange/scripts/browser-check.mjs`를 실행합니다. 두 브라우저의 메시지·사진 공유, 일본어 입장, 텍스트 안전 표시, 나가기, 데스크톱·모바일 화면을 검사합니다. 테스트 서버는 실제 행사 전 종료하세요.
